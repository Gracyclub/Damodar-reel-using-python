# 🦚 Kartik Maas - Divine Damodar & Morpankh Magical Reel

A stunning Python automation script built with **OpenCV** and **NumPy** to generate aesthetic, viral-style devotional reels for Kartik Maas featuring Lord Damodar and floating Morpankh cut-outs.

---

## ✨ Features
* **Magical Morpankh Animation**: 12 transparent feather cut-outs floating slowly from bottom to top against a glowing neon stardust background.
* **Smooth Cinematic Reveal**: Graceful top-to-bottom image reveal powered by a glowing Neon Cyan & Magenta guiding line.
* **Fullscreen Reel Mode**: Configured specifically for clean, borderless screen recording and social media publishing.

---

## 🛠️ Tech Stack & Requirements
* **Language**: Python 3.x
* **Libraries**: OpenCV (`cv2`), NumPy
* **Assets Required**: 
  * `damodar.jpg` (Main background/painting image)
  * `morpankh.png` (Transparent/Black background feather cutout)

---

## 🚀 Run the Script
Make sure your asset images (`damodar.jpg` and `morpankh.png`) are in the same folder, then run:

```bash
python damodar.py
